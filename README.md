## 3. Мутацийн тестийн дүгнэлт

\GradeCalculator.java\ файлын \letterGrade\ функц доторх \score >= 90\ нөхцөлийг зориуд \score > 90\ болгон өөрчлөхөд \
inetyIsExactlyA()\ болон \@ParameterizedTest\ доторх \score = 90.0\ өгөгдөлтэй тестүүд шууд унасан. 
Тест нь \A\ үсгэн дүн хүлээж байсан боловч код \B\ буцааснаас болж \AssertionFailedError\ үүсэж, \BUILD FAILURE\ болсон. Энэ нь манай нэгжийн тестүүд хязгаарын утгуудыг (Boundary Value Analysis) үр дүнтэй шалгаж чадаж байгааг нотолж байна. Хэрэв 90.0 дээрх хязгаарын тест байгаагүй бол энэ төрлийн кодын логик алдаа (Off-by-one error) далд үлдэх байсан.
